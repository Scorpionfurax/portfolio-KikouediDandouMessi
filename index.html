Veille Technologique

Qu'est ce qu'une veille technologique ?

La veille technologique est un processus de surveillance des évolutions et des innovations dans un domaine précis. Elle permet de recueillir, analyser et exploiter des informations sur les nouvelles technologies afin d’anticiper les changements, innover, rester compétitif et saisir des opportunités.

Le sujet de ma veille technologique

Le thème que j’ai choisi pour ma veille est : « L'évolution du Machine Learning : des algorithmes prédictifs à l'intelligence artificielle générative ».
Ce sujet m’intéresse particulièrement car je souhaite orienter ma poursuite d’études vers les métiers de la Data et de l’Intelligence Artificielle. En tant qu'étudiant en développement (SLAM), il est crucial pour moi de comprendre comment nous passons d'une programmation classique, basée sur des règles strictes, à une approche où la machine apprend par elle-même grâce aux données.

Application de facturation — M2L

Objectif : Concevoir une application de facturation permettant au comptable de saisir mensuellement les facturations par ligue, générer et imprimer des factures, et rechercher des factures par critères.

Fonctionnalités :

  • Menu Ligue : création, modification, suppression.
  • Menu Prestation : création, modification, suppression.
  • Menu Facture : saisie guidée d'une nouvelle facture, impression (PDF/print), recherche par date/ligue/numéro/montant.

Contraintes techniques : interface responsive réalisée avec Bootstrap, persistance sur MySQL via la classe PDO (requêtes préparées, gestion des exceptions), code commenté et versionné via Git.

Gestion des employés — M2L (Java)

Contexte : Application fournie en Java, mono‑utilisateur et en ligne de commande.

Objectif : Rendre l'application multi-utilisateurs via une base de données tout en conservant l'architecture 3-tiers.

Habilitations :

  • Employé : consultation/annuaire (lecture seule).
  • Admin de ligue : gestion CRUD des employés de sa ligue via application bureau.
  • Super-admin : gestion globale et administration des comptes d'admin via CLI.

Contraintes techniques : conserver l'architecture 3‑tiers, adapter la configuration Eclipse si nécessaire, sécuriser les accès en écriture et intégrer la base de données. Projet réalisé en Java.
